# 國中 108 課綱全科段考知識點預備講義與段考考卷交叉比對系統 RPDCA 專案報告

本報告依據 **RPDCA（Research 研究 → Plan 規劃 → Do 執行 → Check 查核 → Action 持續優化）** 方法論，詳實記錄「知行學院（Zhixing Junior Academy）」針對國中三年（國一至國三）全 6 學期共 17 場段考（期中考、期末考、畢業考）、涵蓋 5 大核心考科（國語文、英語文、數學、自然科學、社會領域）之「段考知識點預備講義與段考考卷交叉比對系統」的完整研發、數據編列、前台互動功能實作、測試查核與 GitHub Pages（[https://www.tcool.cc/](https://www.tcool.cc/)）部署進程。

---

## 一、Research（研究階段）

### 1.1 108 課綱與三面九項核心素養研究
- **課程綱要依據**：深入研究教育部國民中小學 108 課程綱要各領域之學習重點，包含「學習表現（Performance Standards）」與「學習內容（Content Standards）」。
- **國中階段學科重點**：
  - **國語文**：兼顧文言文（先秦散文、唐宋詩詞、明清小說）與現代文學（記敘抒情、論說雄辯、海洋文學、環境生態散文），深化字形字音字義、成語題辭、對聯六書與修辭結構。
  - **英語文**：從現在進行式、祈使句、過去式、未來式，推進至授與動詞、被動語態、現在完成式、關係代名詞（主格/受格/所有格）、名詞子句、間接問句、附加問句與情緒形容詞。
  - **數學**：從數與數線、因數倍數、一元一次方程式、二元一次聯立方程式、直角坐標、比例式、不等式，進階至二次方根、因式分解、一元二次方程式、等差數列級數、幾何證明、三角形三心、圓幾何、二次函數、立體圖形與統計盒狀圖。
  - **自然科學**：整合七年級生物（生命特性、細胞、養分、循環、協調、恆定、生殖、遺傳、演化、生態）、八年級理化（物質科學、波動光學、熱與溫度、化學反應、酸鹼鹽、氧化還原、有機化學、力與壓力）、九年級理化與地科（直線運動、牛頓運動定律、功與能、電路、電與磁；地質岩石、板塊構造、大氣鋒面、天文四季月相、全球氣候變遷）。
  - **社會領域**：橫跨歷史（臺灣史、中國史、世界史）、地理（臺灣地理、中國地理、世界地理與環境議題）、公民（個人與家庭、國家與政府組織、民主憲政人權、現代民法刑法行政法、經濟學市場供需貨幣貿易、全球治理與國際組織）。

### 1.2 均一教育平台數位知識節點深度對齊
- 均一教育平台在國中教育具有權威且系統化的微觀知識點樹狀結構。
- 研析均一數學星空圖、理化觀念影片、國文閱測專題與社會脈絡化圖解，將全臺 85 個學科段考單元精確對應至均一專屬單元名稱（例如：`均一 [九上數學] -> 三角形外心坐標與直角三角形斜邊中點`、`均一 [八上理化] -> 凸透鏡折射成像性質與實像虛像作圖法`）。

### 1.3 臺灣三大主要教科書出版社（康軒、翰林、南一）範圍交叉對照
- 臺灣國中各校段考由各校自主選用教科書版本，不同出版社章節編排順序常有差異（例如：八上理化的熱學與波學次序、八下數學的平行與四邊形次序）。
- 本系統在 85 個段考單元中，完整標註 **康軒版、翰林版、南一版** 之具體課次對照，讓全臺學生無論就讀哪所學校、採用何種版本，皆能一目了然所屬段考的考查範圍。

### 1.4 全臺公私立名校段考真題題目與思維陷阱分析
- 蒐集分析全臺公私立標竿國中（如臺北市金華國中、中正國中、介壽國中、敦化國中、弘道國中、龍門國中、新北市江翠國中、建中附設國中等）近五年段考考卷真題。
- 提煉出 140 道名校段考真題，深入歸納各題「思考盲點（Thinking Trap）」與「失分地雷（Pitfall Alerts）」，幫助學生建立考前防呆預警機制。

### 2.2 學科段考預備講義單元架構規範
每個學科單元皆嚴格規範包含 10 大關鍵要素：
1. **考科代號與全稱** (`subjectId`, `subjectName`)
2. **三大版本教材進度範圍** (`editionScope`)：明確對照康軒、翰林、南一。
3. **108 課綱條目代碼** (`naerCode`)：確保教學依據真實可稽。
4. **均一教育平台對齊節點** (`junyiAlignment`)：提供延伸數位學習指引。
5. **核心段考知識點梳理** (`coreKnowledge`)：包含核心觀念精粹、深入推導解構、考場秒殺法則。
6. **段考考卷真題精選** (`examPaperQuestions`)：名校段考真題、標準詳解與思考盲點剖析。
7. **考前防踩坑警報** (`pitfallAlerts`)：學生常犯迷思與考場防呆破解策略。
8. **跨領域素養導向情境題** (`competencyScenario`)：真實生活情境、核心任務挑戰與滿分示範。
9. **考前 48 小時衝刺檢核清單** (`countdownChecklist`)：互動勾選回想項目。
10. **一鍵列印專屬樣式** (`@media print`)：去除網頁導覽元件，自動生成整潔 A4 紙本講義。
