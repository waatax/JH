# 會考 AI 解題解析

2026-10-28 已完成 115 年六種考科的 237 題 AI 解析稿：國文 42、英語閱讀 43、英語聽力 21、數學 27（含非選 2）、社會 54、自然 50。每題均有具體解題重點、步驟、提示與易錯提醒；選擇題另有每個選項的說明。選擇題答案已與專案保存的官方答案表逐題核對。非選擇題是 AI 參考解法與自我檢核，不是官方配分標準。

來源入口為 https://cap.rcpet.edu.tw/examination.html 。完整原題、公式、地圖、漫畫與表格以 `dist/downloads/cap/115-*.pdf` 為準。英聽另使用既有官方錄音稿與原圖。AI 推導保存在 `data/cap-ai-derivations/`，並保留來源、題號與作者類型。

## 後續年度的撰寫方式

1. 以 `scripts/build-cap-work.mjs` 產生包含題幹、選項、題組、題圖、錄音稿及官方資料的逐卷工作包。
2. AI 先核對完整題圖與跨頁題組。公式、單位、方向、否定問法、資料年份和法律題的施測背景都須保留。缺材料時先補材料。
3. 撰寫可供學生閱讀的解法：指出條件如何支持結論、列必要計算或文本線索、說明各選項符合或不符合之處。以標準答案檢查最後結論；若不符，重新檢查題圖及推導，不改動官方答案來配合解析。
4. 將具體解析存為與現有檔案相同的 JSON 格式。`answer` 必須與官方欄位完全一致，數學非選題保留 null；不得將通用模板當成逐題推導。`rubric` 僅作 AI 自我檢核，標示非官方配分。
5. 執行 `npm run build:cap-ai`。匯入器先檢查整批資料，攔截不存在的題號、重複題、來源缺失、答案不同、選項說明不齊與已知通用模板，再更新正式題庫與闖關資料。
6. 執行 `npm run test:cap-ai` 及專案測試。數值題另外重算方程、機率、幾何、壓力、濃度等具代表性的結果；核對網頁揭答、題組及英聽播放。

## 呈現與完成狀態

題庫與 Quest 使用共同的 `cap-explanations.js` 呈現合格解析。標示「AI 解題解析」與官方標準答案，尚未經外部教師複核；若答案欄位日後不同，舊推導會退回待補狀態。舊有通用模板在畫面上只顯示解析待補，不冒充完整解析。原模板生成器亦保留已加入的 AI 推導，不會覆蓋。

另已完成 114 年數學 27 題（含非選 2 題）及英聽 21 題的 AI 推導。數學逐頁核對原圖及公式，重算機率、聯立方程、齒輪比、購物預算、重心面積與非選題整數限制；英聽核對官方錄音稿及圖像選項，解釋更正清單、最後決定、慣用語、語意推論與公告主旨。

114 年數學 25 題選擇題的文字版題幹與選項亦已依原 PDF 圖像校訂，補回根號、次方、絕對值、分數及被混入選項的圖號。校訂稿保存在解析來源的 `transcription`，匯入器檢查選項齊全後更新題庫；原擷取內容保留在 `originalExtraction`，`textReview` 記錄 AI 圖像核對來源。幾何圖與表格仍應配合原圖閱讀。

各卷顯示已完成解析題數；全庫機器可讀統計在 `dist/cap-ai-coverage.json`。目前 285 題已加入 AI 解析，其餘 1,389 題尚待逐題撰寫。這些數字計算既有 109～115 年題庫；不包含尚待拆題的 102～108 年、重考及寫作。

相關題目依同科的相同官方評量目標或共同評量代碼推薦，並顯示推薦依據；共同代碼不保證題型或難度完全相同。沒有共同資料時不硬塞題目。

自動檢查能保證資料一致與部分數值關係，不能證明每一條敘述都正確。後續人工或教師審閱可在相同來源檔中修正解析，再重新匯入。

Quest 實測修正：開啟中的關卡列提高層級，避免後方關卡遮住開始按鈕；提示以文字卡持續呈現；長解析放在可捲動的內容區，底部僅保留繼續按鈕，避免解析把題目與按鈕擠出小螢幕。線上載入題庫與解析時重新核對最新版本，離線保留已快取的版本。
