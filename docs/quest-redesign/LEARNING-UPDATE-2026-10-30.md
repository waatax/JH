# Quest 學習流程與朗讀更新

## 目的與執行

延續既有六學期、程度檢測、五階關卡、錯題本與間隔複習，讓初學者可先讀觀念與提示，熟悉者可直接回想作答，答錯後比較判準並再次練習。保留現有內容與學習紀錄格式。

1. 檢查：發現朗讀截斷於 300 字、答案缺少朗讀入口、配對題兩欄原本同序、深色按鈕與解說對比不足。
2. 實作：分段完整朗讀、0.75/1/1.25 倍速、停止播放、題目與選項／觀念／作答後答案與解析四種入口。切換題目會停止舊朗讀；手動朗讀不受音效靜音開關限制。
3. 教材增量：188 個核心單元新增 376 道判準辨識活動，放入思維推演與單元挑戰題池。每題有正解、提示、逐選項比較與回想任務。依各課既有比較表產生，保留來源鍵。
4. 校正：排除判準重複造成的多解題；配對右欄打亂且不全同序；錯配立即比較兩個概念；已完成配對及作答後排序不再接受修改。修正輸入欄快捷鍵與朗讀按鈕 Enter 衝突。
5. 視覺：明示理解／回想／理由階段與題次，改善深色文字對比、鍵盤焦點、窄螢幕工具列及減少動態效果偏好。模擬聯賽明示不是即時真人排名。

## 10% 計算方式

基準是本次擴充前，單元四個教學關卡內不重複的學習活動（含觀念卡與試題）；單元挑戰重用的題目不重複計數。每單元新增 2 道活動，最低增幅 13.33%。計算不是文字字數增量，也不代表新增 10% 課綱範圍。完整逐單元數值見 ENRICHMENT-REPORT.json；產生器再次執行不會累加重複題。

## 驗證

- `npm test`、`npm run build`：通過。含既有課程、評分、錯題、離線更新與 67 項 Quest 整合檢查。
- `scripts/quest-learning.test.mjs`：逐一檢查 188 單元增量、題池可達性、來源與選項解析；測試超過 300 字不截斷、中英語言選擇、停止後不續播、不支援朗讀時提示、作答前朗讀不洩漏正解。
- 瀏覽器：本機實際載入闖關、切換語速、進入配對題、選錯並看到即時解說。語音輸出取決於裝置可用語音，未以人工聽辨驗證每個字的發音。

## 已知界線

本次擴充涵蓋 188 個核心單元，分支重用相同單元內容；歷屆會考卷與段考卷未改寫為新增原創題。圖片型會考題只能朗讀現有文字與選項字母，不對圖片內容臆測朗讀；尚待審閱的會考解析仍保留狀態標示。比較表內容沿用專案資料，未聲稱經全學科專家逐題審訂。

發布時保留工作區既有會考解析、教材來源典藏與相依測試更新，避免新題池引用未發布的依賴。學習資料仍只在瀏覽器本機保存。
