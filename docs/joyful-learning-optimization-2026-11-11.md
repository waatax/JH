# 2026-11-11 知行學院（JH）國中生快樂學習 × 全知識點與可能題型制霸 × 愛上學科深度更新報告

## 一、 閉環方法論（思考 ➔ 研究 ➔ 規劃 ➔ 優化規劃 ➔ 執行規劃 ➔ 確認效果 ➔ 優化結果 ➔ 迭代）

### 1. 深度思考與研究（Thinking & Research）
針對目標族群「國中生（七～九年級）」的學習心理與認知痛點進行全面剖析：
- **為什麼國中生會覺得學科枯燥？** 傳統講義一打開就是生硬的專有名詞與公式，缺乏「這門課在生活、遊戲、運動、流行文化中有什麼超能力？」的動機連結。
- **為什麼知識點背了卻不會用？** 靜態表格容易看過就忘，需要「主動翻卡自測（Active Recall）」與「30 秒閃電三連擊 Combo 闖關」讓大腦產生即時多巴胺回饋。
- **為什麼會考與段考變形題會卡關？** 每個單元的三大可能題型（Type A 基礎定義直球題、Type B 圖表數據與雙情境對比題、Type C 逆向反推與邊界壓軸題）除了看懂破題 SOP，更需要**立即動手破關並收集題型制霸印章**。

### 2. 規劃與優化執行（Planning & Execution）
1. **愛上 21 門知識學科超能力引擎（`subjectLoveData` in `dist/joyful-learning.js`）**
   - 為八大領域 **21 個學科**全數打造專屬「學科超能力封號」（如：數學＝`🔮 宇宙規律與機率破解師`、理化物理＝`⚡ 時空、能量與光電魔導師`、生物＝`🧬 生命演化與生態密碼偵探`、歷史＝`⏳ 時空旅人與文明劇本導演` 等）。
   - 每科配備 **3 項國中生超有感的生活魔法應用**、**快樂學好秘訣（`joyfulHack`）**、**知知貓頭鷹鼓勵語**，以及可點亮的 **「💖 我喜歡這門學科」徽章（+15 XP）**。
2. **全站 188 單元「趣味生活超能力 × 驚喜冷知識 × 考場秒殺記憶口訣」（`unitWonderData`）**
   - 每一單元開篇新增 `step-unit-wonder` 趣味破冰模組：結合青少年生活情境、80% 考生最常踩中的趣味冷知識、朗朗上口的四句**🎵 快樂秒殺記憶口訣**（支援 `🔊 語音朗讀口訣` 與 `📋 一鍵複製`），以及點擊揭曉的**🧠 腦筋急轉彎快問快答**。
3. **全站 564 點「🃏 知識點記憶翻翻樂」與 564 題「⚡ 知識點閃電三連擊 Combo 遊樂場」**
   - 將每單元 3 大核心知識點轉化為互動式翻翻卡（正反面自測＋`✅ 我學會了！蓋上精通印章 (+10 XP)`），搭配 3 題快速連擊挑戰（`🔥 Combo x1 ➔ x2 ➔ x3 MAX!`），全對即頒發該課 **🏅 知識點閃電三連擊制霸金章（+20 XP）**。
4. **全站 564 道「⚔️ 三大可能題型（Type A / Type B / Type C）互動實戰快篩與集章」（`archetypeDrill`）**
   - 於 `dist/exam-types-data.js` 的 188 單元 × 3 大可能題型（共 564 個題型模組）中，全面嵌入互動式四選一破關快篩題（`archetypeDrill`）與題型制霸印章追蹤器，達成 3 題型全破關即點亮「🎊 本課三大可能題型 100% 大滿貫」橫幅！
5. **首頁「🦉 知知貓頭鷹驚喜轉盤」與「🎮 JH Quest 遊戲闖關島全面升級」**
   - 首頁（`#/home`）新增每日學科驚喜冷知識與口訣轉盤、全站知識點與可能題型制霸總覽雷達，以及「🎲 隨機抽一題可能題型立即破關」快篩台。
   - 課程與學科頁面的單元卡片（`unitCard`）即時顯示該單元的 `🃏 知識章 X/3 · ⚔️ 題型 X/3` 收集進度（迭代優化）。
   - JH Quest（`dist/quest/`）全站 **5,408 個學習互動項目**：將 564 道 Type A/B/C 可能題型挑戰注入各單元關卡池與 Boss 池，單元指南新增「✨ 趣味與口訣」分頁，並將 36 篇跨領域探究故事（`stories.json`）的選項全面升級為真實學科誘答選項。
