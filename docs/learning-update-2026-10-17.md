# 教學頁面改善與驗證紀錄（2026-10-17）

## 範圍與依據

更新現有 21 科、188 課的一般教學頁與全螢幕工作台；保留原有 188 幅專屬 SVG、比較表、例題與題庫。新增內容由現有課程、原創題目解析與各科學習策略組成。沒有將共用提示計為獨立的新學科知識點。

官方參照：國家教育研究院 https://www.naer.edu.tw/PageSyllabus?fid=52 及領綱索引 https://stv.naer.edu.tw/teaching/course_outline.jsp 。本次查詢確認官方入口；未逐份重審所有領綱原文、所有指標或全部教材事實。

## 七項檢查、修正與再驗證

1. **目標與範圍**：檢查既有教學結構；補上全部 188 課的概念、條件、任務學習地圖。逐課執行模組渲染確認資料可用。
2. **圖表可讀性**：檢查新增內容與原比較表的重複；將重複的表格改為「目標／證據／未達成時修正」，保留每課實際例題與迷思。新增響應式概念關係圖與語意表頭。
3. **科目適切性**：檢查共用方法是否適合各領域；加入 21 科共 42 條原創學習策略，以及八領域各三項證據要求。實作、口說與手語明確需要作品或教師回饋。
4. **回想與修正**：檢查先看答案的學習流程；新增兩層折疊的原創練習及答案解析，使用既有 376 題，不宣稱新增題目。修正提示連接各課既有教學與驗算條件，加入隔天再回想流程。
5. **課綱可追溯性**：盤點現有 alignment-data；只有 25 課已有章節關聯，另 163 課明示待補。新增可重建的逐課來源索引，來源代碼全部標為待審，不把主題關聯當作官方覆蓋認證。
6. **入口與可及性**：檢查一般頁／工作台兩處整合；新增內容納入既有搜尋。加入鍵盤焦點、窄螢幕單欄、可捲動表格與文字轉義檢查；以不同標題的注入測試確認動態文字不能當作 HTML 執行。
7. **發布與回歸**：新增七組回歸測試並納入 npm test；更新離線快取版本與三個新模組清單。完成 npm test、npm run build 與 git diff --check。部署以 GitHub Actions 與線上資產結果另行核對。

## 驗證限制與後續工作

七組測試是可重現的軟體檢查，並不等於七輪完整學科專家審查。本機預覽服務可啟動，但瀏覽器工具連線逾時，未完成本機視覺與行動裝置端到端驗證。未重製下載用 PDF 講義。

使用者所要求的「徹底依照全部課綱」仍需逐條建立官方學習表現／學習內容分母、核對教學證據，並由各領域教師審查。此更新完成現有教學頁面的學習鷹架與來源透明度改善，不宣稱已補足所有語別、本土語文、臺灣手語或全部實作課程。
