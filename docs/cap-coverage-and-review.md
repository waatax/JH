# 會考題庫覆蓋與校訂紀錄

本專案互動題庫目前收錄民國 109 至 115 年正式會考。另已核對官方年度選單與實際連結，下載 102 年試辦、103 至 108 年正式會考，以及 105 年新店考場重考共 66 份原始檔案，尚未拆題。官方歷屆題本入口：https://cap.rcpet.edu.tw/examination.html 。

會考包含國文、英語（閱讀與聽力）、數學、社會、自然及寫作。既有題庫 1,674 題包含國文 306 題、英語閱讀 297 題、英語聽力 126 題、數學 191 題、社會 396 題與自然 358 題；數學包含 14 題非選擇題。109 年既有資料缺英聽，寫作不在上述題目數中。

闖關依年份和科目分題池，每回合抽題；具答案與題圖的 1,660 題選擇題可從對應科目進入，110 至 115 年英聽獨立成關並可播放錄音。數學非選擇題與寫作未納入闖關自動評分，原始題本仍可透過既有會考功能查閱。闖關不是將每題重新編寫成新的情境題，而是以原題圖和題組圖結合遊戲機制練習。

官方答案已依現有資料結構核對；題圖存在、題組圖與音檔路徑均經自動檢查，但這不等於逐題人工校正裁切、題意或文字。部分題目裁切可能不完整，需開啟題本核對；文字擷取及圖表亦需逐題核對。2026-10-28 已完成 115 年六種考科 237 題與 114 年數學 27 題、英聽 21 題，共 285 題 AI 解析稿，其中選擇題 281 題已同步到闖關。其餘 1,389 題的既有生成解析多為通用模板，畫面標示待補。完整進度及匯入流程見 `docs/cap-ai-explanation-workflow.md`。

歷史來源清單保存在 `data/cap-historical-sources.json`，下載器為 `scripts/download-cap-historical.py`，各檔案格式、大小、SHA-256 與來源保存在 `dist/cap-historical-manifest.json`。102、103 年英語題本含聽力，另有音訊檔；105 年重考與正式題本使用不同檔名。主站典藏區可開啟這些原始檔案及既有 109～115 年寫作題本。典藏不等同完成拆題，未加入 1,674 題統計。

66 份檔案包括 59 份 PDF、6 份 ZIP、1 份 MP3，共約 252 MB。`scripts/audit-cap-historical.py` 已確認 709 頁 PDF 的頁物件與內容串流可解析，ZIP 通過 CRC 檢查，檔案大小與 SHA-256 相符。結果保存在 `docs/cap-historical-source-audit.json`；此項結構檢查不等同逐題閱讀或音訊播放審核。

主頁原有未附來源的長文圖表命題百分比已移除，改由題庫實際計算年度題數與 AI 解析進度；未附官方來源的未來考期倒數亦移除。

本輪驗證：`npm test`、`npm run build`、`git diff --check` 通過；會考嚴格結構稽核為 0 個硬性問題、51 個提醒（例如題圖高度與選項擷取），提醒仍待逐題核對。瀏覽器實測可開始闖關、顯示提示、核對答案及閱讀相關題；390×844 的畫面中長解析置於可捲動內容區，繼續按鈕保持在可見範圍，無水平溢出。

114 年英聽第 12 題已實測播放與暫停官方錄音，畫面顯示新版 AI 推導、選項解說及官方試題分析頁連結。另修正統計呈現：缺少的等級比率不再顯示為 0%，英聽三選項題不再顯示不存在的 D 選項；實際存在的 0 值仍保留。

後續應拆分已取得的早期題本並保留跨頁題組與圖表；核實 109 年英聽未列於索引的原因、補齊非選題練習與寫作；逐題核對原題和答案，再編寫包含關鍵條件、推理過程及錯誤選項原因的解析。對第三方素材應另行核實使用權限。完成每卷後以題號、題組、音檔、題圖與答案對照官方資料，再進行閱讀與操作測試。
