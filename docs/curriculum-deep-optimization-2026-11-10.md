# 2026-11-10 國中全科教學頁面深度優化與會考題型回推五步詳解工程紀錄

## 一、工程目標與指導思想

本輪優化針對知行學院（JH Academy）國中 108 課綱六學期全站 188 個單元（涵蓋 7～9 年級國文、英語、數學、生物、理化、地科、歷史、地理、公民、藝術、健體、科技、綜合活動等），嚴格踐行使用者提出的七階閉環方法論：
**（深度思考 ➔ 規劃 ➔ 優化規劃 ➔ 迭代規劃 ➔ 執行 ➔ 效果確認 ➔ 優化）**，徹底達成：
1. 以近七年會考（109～115）真題大數據與 108 課綱指標為基準，逆向回推檢驗教學頁面中的知識點是否足以支撐學生作答；
2. 對照康軒、翰林、南一三大版本教科書編排差異與微觀考點，補齊跨版本考生的概念斷層；
3. 為每個單元教學頁面後配置真實大考風格之高頻例題練習、4 選項互動點擊即時反饋、與五步階梯式鷹架全方位詳解；
4. 全面擴展「零基礎小白 ➔ 會考 A++ 頂標」三階精熟天梯；
5. **為全站 188 個單元實打實擴增 30% 以上的實用學習內容**，並完成自動化驗證與 GitHub Pages 發布。

## 二、七階閉環實施紀錄

### 1. 深度思考（Deep Thinking）
- **真題回推分析**：深入分析 109～115 會考官方試題。統計發現會考題目具有高度的情境化、圖表轉譯與概念本質考查特點，純死記硬背無法拿分。學生常反映「讀懂了課本概念，卻不會做會考題」，其根源在於「題眼線索識別」與「極端盲點防禦」存在知識斷層。
- **學科知識鏈回推**：
  - **數學科**：從生活最佳化建模、幾何幾何母子相似比、二次函數極值逆推，要求教學頁面必須具備嚴謹的代數推導與幾何性質對照。
  - **國文學科**：從文言短文閱讀、字詞古今異義、六書判準、修辭美學逆推，要求頁面提供精確語境字義推求方法。
  - **英語學科**：從時態混淆（現在完成式 vs 過去式 vs 被動語態）、關係代名詞/名詞子句、克漏字上下文邏輯逆推，提供結構公式與易錯盲點。
  - **自然科（生物/理化/地科）**：從浮力動態浮沉轉變、歐姆定律串並聯分流電阻、光合作用碳反應、板塊構造與等壓線風向逆推，提供受力平衡圖、微觀化學反應式與三維空間幾何模型。
  - **社會科（歷史/地理/公民）**：從歷史時空座標、地理等高線與氣候圖判讀、公民憲法救濟與市場供需曲線逆推，提供因果時間軸、空間模型與法理框架。
  - **藝體科技生活科**：從急救 CPR+AED 流程、程式演算法、生活科技機構傳動逆推，提供標準作業程序與科學邏輯。

### 2. 規劃（Planning）
規劃四大模組結構：
- Module 0: 零基礎小白 ➔ 會考 A++ 頂標 三階通關藍圖
- Module 1: 108 課綱 x 歷屆會考 題型分析與知識點回推審計矩陣
- Module 2: 歷屆會考改編 高頻例題練習（4 選項互動點選、即時反饋）
- Module 3: 五步階梯式鷹架全方位詳解（審題 ➔ 定理 ➔ 推導 ➔ 逐項剖析 ➔ 版本心法）

### 3. 優化規劃（Optimized Planning）
- **量化指標設立**：將本次優化前全站 188 單元的字數基線（575,580 字）精確凍結於 `docs/expansion-pre-opt-baseline.json`；
- **嚴格驗證標準**：要求**全站 188 個單元每一個單元的實質字元數相較優化前基線增長率均 ≥ 30%**，杜絕無意義灌水，新增內容全部為具體扎實的知識審計、版本對照、解題推導與選項剖析。

### 4. 迭代規劃（Iterative Planning）
分五大學科領域推進自動化擴增管線：
- 數學領域（27 單元）
- 語文領域（國文 22 單元 + 英文 18 單元 = 40 單元）
- 自然領域（生物 12 單元 + 理化 20 單元 + 地科 7 單元 = 39 單元）
- 社會領域（歷史 16 單元 + 地理 16 單元 + 公民 16 單元 = 48 單元）
- 藝體科技生活領域（34 單元）
