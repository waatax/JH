# 2026-11-03 學習品質與手機體驗改善

本次以「學生知道下一步、內容與圖一致、評量能指出補強方向」作為驗收目標。沿用 GitHub Pages 與既有 188 個核心單元、六學期、21 科及考試資料，沒有把網站架構齊全宣稱為所有版本教材已逐頁審訂。

## 研究與決策

- [國教院課程綱要入口](https://www.naer.edu.tw/PageSyllabus?fid=52)用於核對總綱與領域課綱的官方來源。出版社章節、學校授課順序與本站核心單元是不同層次，介面應分別標示。
- [Retrieval Practice in Classroom Settings: A Review of Applied Research](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2019.00005/full)討論課堂提取練習與回饋的研究。據此採取的產品設計是先試答、再看解釋、安排回想；這是設計推論，不代表本網站已證實提升學習成效。
- 1／3／7／14／30 天是本站採用的固定複習規則，不是個人化記憶模型或已證實對所有學生最佳的間隔。

## 盤點發現與完成的迭代

1. **入口與選擇過載**：重做主站首頁，提供課堂教材、短關卡、暖身與複習入口。Quest 先呈現今天的一小關，再提供學期、科目、版本與搜尋。完整地圖可展開，各單元也可收折。選擇、搜尋、推薦使用同一範圍。
2. **評量與進度**：觀念卡不納入答題分母；首次獨立答對、提示與配對修正分開記錄。重複點擊不會重複計分或扣心；無法跳過未答的評分題。修復回合不當成新的獨立答對證據，錯題需在後續練習獨立答對兩次才畢業。複習成功會延長間隔，輔助或低表現會回到一天。
3. **圖文一致性**：舊生成器依學科名稱套用循環、守恆等圖形，部分內容與知識點標題不一致。重建全部 564 張卡與 SVG：直接使用同單元原創比較表前三列，保留完整概念、規則與實例。數線示例採真實等距刻度；其他卡片明示閱讀順序，不捏造因果或比例。移除無根據的考頻權重、充要條件套話及跨科規則完全一致的宣稱。每點記錄來源單元與列號。
4. **評量題意**：知識點題改用同表實際定義、特徵、對照描述與示範步驟，補逐選項說明。避免「完整定義」與其同義簡述同時成為不同選項。移除要求逐字背出整段公式說明的精確文字輸入題。題庫現在有 4,468 筆活動（含觀念卡、練習與故事），不是 4,468 道獨立考題。
5. **裝置與閱讀**：調整柔綠配色、主要按鈕、觸控區、頂欄密度與安全區；圖解可開啟原生放大對話框並橫向捲動，表格保留手機卡片模式。指南先呈現核心與圖，額外回想方法可展開。遮答以真正隱藏內容處理；對話框提供焦點範圍與 Escape 關閉。資料生成採原子寫入，避免 Windows 同步資料夾中短暫鎖定或部分 JSON 被讀到。

## 實際驗證

- `npm test`：114 個測試及另行執行的 7 個 Quest 引擎測試通過；另完成全站靜態檔案、內容、連結及健康檢查與 72 項 Quest QA 檢查。
- `npm run build` 通過。測試包含 564 張卡的來源列一致性、圖解文字完整換行，以及 13 項學習路徑與評分回歸測試。
- 瀏覽器實測 320×740、390×844、768×1024、844×390、1366×900：Quest 首頁沒有文件層級的橫向溢出。320、390、768 與 1366 尺寸的第一個開始按鈕可在首屏看到；低高度橫式需要捲動，題目與材料仍可閱讀。
- 實際完成數學概念關：一張閱讀卡、三道評分題，其中一題先錯配再修正；結果為 **2／3 題獨立首次答對、1 題輔助**，成長頁顯示數學 67%，未練領域顯示「待探索」。
- 檢查科目篩選會同步改變推薦與單元清單、圖解放大、鍵盤關閉與回想遮答，主站手機及桌機無水平溢出，未發現瀏覽器錯誤紀錄。
- 代表性截圖位於 [previews](previews/)。這些是開發測試紀錄，不是每課都經過人工教學審查。

## 版本涵蓋與仍需完成的審訂

目前 188 單元中，有公開章節來源的單元數為：**康軒 24、翰林 4、南一 6**（可重疊）。其餘仍可使用原創核心教材，但章節、年度、冊次與頁碼待核對。來源紀錄也不表示已檢查最新年度；已在指南呈現實際數量及來源連結。

本次的 564 張圖文一致性檢查不能取代學科專家審查，亦未逐條完成所有官方課綱代碼及各版本全冊內容對應。下一階段應取得可核對的各版年度目錄與課程計畫，逐單元審訂學習表現、學習內容、先備條件、教材頁次與評量情境，再進行學生可用性及延宕回想測試。

紀錄仍儲存在各瀏覽器本機；XP、關卡完成比例與模擬聯賽不等於能力分數。舊進度保留，無法從舊總答對數反推獨立答題能力。
