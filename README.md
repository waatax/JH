# 知行學院｜國中全科學習與大考歷屆模考

網站：https://waatax.github.io/JH/

以臺灣 108 課綱國中階段與大學學測（GSAT）為參照的綜合自學與模考平台：
- **國中全科核心**：188 個單元、460 道檢測題、188 份 108 課綱專屬比較表（1,137 列，100% 獨立不共用）、188 幅全單元核心思維掌握導圖與專屬 SVG 概念圖解（100% 全單元覆蓋）。
- **六學期複習講義**：188 份單元講義 PDF 與版本（康軒／翰林／南一）課綱對照。
- **近七年會考官方題庫**：109～115 年會考官方試題、解答、英聽 MP3 與官方評量目標。
- **學測歷屆全科模考**：收錄 108 至 115 學年度（8 個年度、53 場考科、2,216 筆官方試題轉錄資料），支援計時練習與可核對題目的答案比較；非選題、缺漏答案或不完整題型待人工評閱，不推估級分。
- **174 份官方 PDF 存檔**：試題、答案、評分原則與答題卷，以目錄 SHA-256 核對檔案完整性（不等於轉錄文字與題型皆已審訂）。

## 學習與測驗功能

- 每課包含 108 課綱核心思維導圖（概念起點、判準法則、避坑防線、遷移解題）、專屬比較矩陣、示範、迷思、遷移任務、筆記、自評與兩題驗收。
- 收藏單元、全域關鍵字檢索、學習紀錄、錯題與 1／3／7／14 天跨日固定間隔複習。
- 國中五科會考模擬考場、英語合成語音聽力、數學非選擇題自評與 50 分鐘寫作練習。
- 學測全科（國綜、國寫、英文、數A、數B、社會、自然）線上計時練習與逐題練習模式。
- 題組閱讀材料雙欄分割閱讀器（支援字級縮放與行動裝置響應式排版）。
- 互動實驗室（數學、理化、生物、地科互動模擬實驗）、列印筆記與本機學習資料 JSON 匯出備份。

## 開發與驗證

使用 Node.js 20 以上，無任何第三方套件依賴。

```sh
npm test
npm run build
npm run dev
```

本機伺服器網址為 http://127.0.0.1:4173/ 。build 與 test 會驗證題目結構、題庫數量、單元表格、圖解格式、學測資料庫與所有本機靜態檔案。

## 檔案與發布

- `dist/curriculum.js`、`cases-*.js`：國中全科課程與延伸思考。
- `dist/teaching.js`：各單元比較表與教學呈現。
- `dist/diagrams.js`：專屬教學圖解 SVG。
- `dist/study-library.js`：六學期講義、版本對照與會考歷屆題庫模組。
- `dist/gsat-interactive.js`：學測歷屆全科模考與互動測驗引擎。
- `dist/gsat-database.json` & `dist/gsat.db`：學測 53 卷 2,216 題官方題庫與 SQLite 資料庫。
- `dist/downloads/gsat/index.html`：174 份官方 PDF 下載與校驗總目錄。
- `.github/workflows/deploy.yml`：推送 `main` 分支後，自動執行測試並將 `dist/` 發布至 GitHub Pages (`waatax.github.io/JH`)。

資料只存在目前瀏覽器（localStorage），不跨裝置同步。匯出備份包含個人筆記與作文，請妥善保管。


## 2026-09-24 校正與教材增量

保留目前版本的講義、會考與學測資料。相對 c54dc06 的國中教材文字基準，188 課新增 188 組原創講解與示範、564 個推理步驟，有效文字增加 38.55%，每課至少 20.34%。計算不含程式碼或介面字樣；詳見 docs/expansion-report.json。此增量不表示已逐條覆蓋全部官方課綱代碼。

學測題庫轉錄仍有題型邊界、公式及圖片缺漏的風險，作答請對照原始 PDF。新版移除任意文字自動給非選題 70% 分及線性級分推估；比較值使用每題一單位，並非官方配分。舊版成績保留原資料但不再顯示不可靠分數。

學測作答改以唯一題目 ID 保存，避免重複題號覆蓋答案；各試卷與模式分開自動保存答案、標記、閱讀位置及字級，可重新整理後續答。計時模式保留原截止時間，離開後仍計時；返回時已到期會交卷。未勾選選項或空白文字不計入已答題數。無法使用瀏覽器儲存時會顯示提示，當次成績仍可在記憶體中查看。

驗證包括 16 項評分／計時／複習／續答單元測試，以及題目 ID 唯一性、學測、會考與講義的檔案大小、現有雜湊及 PDF 標頭檢查。靜態檢查不等於瀏覽器端到端測試或學科專家審查。
