# 知行學院｜國中全科學習

網站：https://waatax.github.io/JH/

以臺灣 108 課綱國中階段為參照的原創自學網站，目前有 188 個單元、460 題、188 份單元比較表（755 列，相關單元共用部分整理）及 65 幅專屬 SVG 圖解。課程數量不等於官方指標完整覆蓋，內容範圍與尚待補強項目見 [教學盤點](docs/teaching-audit.md)。

## 學習功能

- 每課包含概念拆解、規則與例子比較表、示範、迷思、遷移任務、筆記、自評與兩題驗收。
- 收藏、全文檢索、學習紀錄、錯題與 1／3／7／14 天跨日複習。
- 國文、英語閱讀、數學、社會、自然及合成語音聽力模擬練習；另有數學非選擇題與寫作自評。
- 互動實驗室、列印筆記與本機學習資料匯出。

本站不是官方會考試題；答對率不換算 A++，兩题答對不代表精熟。口說、動作、藝術與實作需要教師或同儕回饋。國中升學對應教育會考，學測則是高中升大學考試。

## 開發與驗證

使用 Node.js 20 以上，無套件安裝需求。

```sh
npm test
npm run build
npm run dev
```

本機網址為 http://127.0.0.1:4173/ 。build 會檢查題目結構、題庫數量、單元表格、圖解格式與本機資產連結，並更新 docs/content-inventory.json；它不是教學內容的專家審查，也不會逐一驗證外部網站連線。

## 檔案與發布

- dist/curriculum.js、science.js、social.js、life.js：課程內容。
- dist/teaching.js：各單元比較表與教學呈現。
- dist/diagrams.js：專屬圖解；不再用通用流程圖補足圖解數量。
- dist/engine.js：作答、計時、評分、複習排程。
- .github/workflows/deploy.yml：推送 main 後，通過測試再將 dist 發布至 GitHub Pages。

資料只存在目前瀏覽器，不跨裝置同步。尚未提供 Service Worker，因此不保證離線重新開啟。匯出備份包含個人筆記與作文，請自行保管。
