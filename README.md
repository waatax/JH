# 知行學院｜國中全科學習系統 (Junior High Academy)

> 以 108 課綱為核心，涵蓋國中三年（七至九年級）八大領域、21 個學科、156 個核心章節主題、396 道原創觀念驗收與會考題組，具備互動實驗室、會考命題寫作、錯題間隔複習與完整學習歷程管理。

🌐 **線上訪問網址**：[https://waatax.github.io/JH](https://waatax.github.io/JH)

---

## 核心設計理念與架構

1. **理解 → 練習 → 遷移**：
   - 每個教學章節均包含四大步驟：
     - **01 / UNDERSTAND**：深度概念解析，打破死記硬背。
     - **02 / WORK IT OUT**：典型實例推導與「常見迷思」深度剖析。
     - **03 / MAKE IT YOURS**：主動回想解釋、生活實作任務、自評規準與個人筆記。
     - **04 / 觀念驗收**：雙題即時驗收，附完整解題推理與引導提示。
2. **對齊臺灣教育部 108 課綱（第四學習階段）**：
   - **語文領域**：國語文（12 單元）、英語文（12 單元）、本土語文／臺灣手語（4 單元）。
   - **數學領域**：數學（20 單元，涵蓋數與量、代數、幾何、三心、函數、統計與機率）。
   - **自然科學領域**：生物（12 單元）、理化・物理（13 單元）、理化・化學（12 單元）、地球科學（10 單元）。
   - **社會領域**：歷史（12 單元）、地理（10 單元）、公民與社會（9 單元）。
   - **藝能與生活領域**：視覺藝術（3 單元）、音樂（3 單元）、表演藝術（3 單元）、資訊科技（3 單元）、生活科技（3 單元）、健康教育（3 單元）、體育（3 單元）、家政（3 單元）、童軍（3 單元）、輔導（3 單元）。
3. **會考型模擬考場與題庫**：
   - 包含國文、英語閱讀、數學（含非選擇題）、社會、自然、英語聽力（語音合成支援）全科會考規格模擬卷。
   - 長篇素養題組、圖表判讀題與跨領域資訊整合題。
4. **艾賓浩斯間隔複習系統**：
   - 錯題與看過提示的題目自動納入間隔複習排程（1 天、3 天、7 天、14 天跨日提取）。
5. **虛擬互動實驗室**：
   - 二次函數拋物線頂點探究、歐姆定律電路、槓桿力矩平衡、英語時態四維變換。
6. **零依賴・極速純前端原生架構**：
   - 無需繁瑣打包流程，純原生 ES Modules，全靜態檔案，即開即用，支援斷網與本機 LocalStorage 儲存備份。

## 本地開發與測試

```bash
# 1. 執行核心測驗引擎測試
npm test

# 2. 執行 108 課綱全科內容、題目規範、連結有效性全自動校驗
npm run validate

# 3. 啟動本地開發伺服器
npm run dev
```
